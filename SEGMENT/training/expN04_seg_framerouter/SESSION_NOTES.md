## 2026-09-05 汚染度測定（expN04 は held-out を持たない）

**目的**: expN04 は `train_part: all` で 130 動画すべてを学習に使ったため手元に held-out が無い。
測ったのは汎化性能ではなく **暗記が構成間の差を潰すか**＝構成探索がローカルで成立するか。

**★`lopo_v001` も使えない**: `v004` と `lopo_v001` は**同じ130動画を切り直しているだけ**
（v004: heico6+lapchole20 が fold0 val / lopo_v001: fold0 val = lapchole 100本）。
130本全部を学習した expN04 には **LOPO も全部汚染**。
→ **LB と相関する唯一のローカル指標**（in-dist CV 0.7197 / LOPO 0.5273 / LB 0.5692）を失った。
`train_part: all` の真の代償はここ。当時の判断材料には挙げていなかった。

### 結果（fold0 val n=1958, judge=Qwen3.5-4B, dl1 Quadro RTX 8000）

| モデル | A 64f@560 | B 32f@768 | 振り分け合成 |
|---|---:|---:|---:|
| expE06g（クリーン） | 0.7113 | 0.7197 | **0.7345** ← 合成が最良 |
| v012 = expN01B ck2481 s0（クリーン） | 0.6886 | 0.6920 | **0.7080** ← 合成が最良 |
| **expN04（汚染）** | **0.7748** | 0.7524 | 0.7635 ← **合成が A 単独に負ける** |

### 水増しの定量（対戦相手を LB と同じ v012 に揃える）

| | v012 | expN04 | Δ | 水増し |
|---|---:|---:|---:|---:|
| LB ID 平均 | 0.6192 | 0.6420 | +0.0228 | — |
| ローカル 合成 | 0.7080 | 0.7635 | +0.0555 | **+0.0327（伸びの59%）** |
| ローカル A 単独 | 0.6886 | 0.7748 | +0.0862 | +0.0634（伸びの74%） |

**判定**: 事前に置いた「軽微」帯（0.75〜0.79）に着地。
- **使える**: 同一モデル内の**対応のある**構成比較。暗記は両アームに等しく効くので
  差は**潰れる方向にしか歪まない**＝保守的（差が出たなら本物寄り）
- **使えない**: 絶対値 / モデル間比較 / OOD に関わる判断

### ★推論時の振り分けの利得が消え、符号が反転（ただし有意ではない）

`v005` router で B(32f@768) へ回す 314問での B の優劣:

| モデル | B勝ち/B負け | Δ正答 | p |
|---|---:|---:|---:|
| expE06g（クリーン） | 21 / 9 | **+0.0382** | 0.043 |
| v012（クリーン） | 18 / 8 | +0.0318 | 0.076 |

機序は筋が通る（学習側で振り分けたので推論時の振り分けが不要になった）が、
**discordant が 27 ペアしかなく反転自体は有意でない**。3モデルで方向が単調な点が支えだが、
これ単独で採用を決める強さはない（[[small-bucket-significance]]）。

### 記録の訂正（20260904.md）

- **「v012 の CV = 0.6704」は提出構成と対応していない**。0.6704 は `s1rules`（重畳あり）の値で、
  v012 は**重畳なし(s0)** の提出。`expN00` の評価は**すべて単アーム 32f@768** なので
  `0.7075` は単アーム値であり、合成値 `0.7080` と横並びにしてはいけない。
  提出構成で揃えると v012 単アーム 0.6920 vs v013 0.7075。
  → **「CV 最良が LB 最下位」の結論自体は成立**（CV +0.0155 で LB −0.0553）。
    ただし **CV 差は 0.0371 ではなく 0.0155** で、記録は差を 2.4 倍に誇張していた。
- **`event_understanding` の「4提出連続で低下」はノイズ**。n=20 で 0.6→0.5→0.4→0.45 は
  2問・2問・1問の差。「SCORE の SE ≈ 0.025 / 実効サンプル382問」と整合しない。
- **手元 val と LB は同じ ID でも別物**: event_understanding は 手元 n=74 で 0.824 /
  LB n=20 で 0.450。手元 val には `ood=1` が 0 件。
