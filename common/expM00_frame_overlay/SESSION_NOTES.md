# expM00 — instseg 重畳を**学習に入れた** FRAME モデル（リーク対策込み）

開始 2026-09-01。狙いは「検出器の出力を推論時だけ見せる」から
「**学習から見せる**」への切り替えと、そのときに必ず要る**リーク対策**。

## 1. 何が問題か

- 現行コンテナ（v008）は推論時だけ重畳を足している（dual）。LB では効いている（ユーザ確認済み）が、
  モデルは重畳を見たことがないまま使わされている。
- 重畳を学習に入れるなら、**検出器がその動画の注釈で学習していないこと**が要る。
  そうでないと「検出器が GT を暗記した重畳」を教師にしてしまい、テスト（未知動画）と別物になる。

## 2. arm 分割（`build_arms.py` → `overlay_arm_v001.csv`）

検出器 expF40 / expF39 は `instseg_v004` fold1 = 104 動画で学習。

| arm | 定義 | 動画 | FRAME train 問 | heico / lapchole |
|---|---|---|---|---|
| **DUAL** | 検出器が学習に使っていない | 68 | **9,897** | 5,600 / 4,297 |
| **CONTROL** | 検出器が学習に使った | 36 | **6,095** | 4,000 / 2,095 |
| CONTROL（擬似QA） | 生成元が必ず det-train 動画 | 104 | **15,906** | pseudo v2 11,433 + cutpaste 4,473 |

合計 31,898（expK01F は 28,133）。**回答形式の構成比は K01F とほぼ同一**
（fo_class 41.9 / number 36.9 / binary 8.7 / open_ended 7.7 / MC 4.8 %）。

★**`instseg_v004` は qa-aligned に切ってあるので、qa fold0（VLM の val）26 動画に
det-train 動画は 1 本も無い**（assert 済み）。CV は重畳込みで leak-free に測れる。
なお val 4,008 問のうち 1,603 問は検出器の **model selection に使った 8 動画**由来なので、
「instseg データセットに一度も居ない 18 動画 2,405 問」の内訳も併せて見る。

## 3. 2026-09-01 の見直しで直した実装の不備 3 件

| # | 不備 | 影響 | 対処 |
|---|---|---|---|
| ① | 重畳のラベルが**内部クラス名**（`Silicon_Loop` / `Specimen_Bag` / `sponge`） | 回答語彙は `Silicone Loop` / `Specimen Bag` / `Sponge`。**綴りまで違う**（Silicon vs Silicone）。`ALIASES` は text 経路にしか当たっていなかった | `OFFICIAL` で公式表記に正規化 |
| ② | **原寸に描いてから縮小**していた（コンテナ） | test frame は heico 960x540 / lapchole 1280x720 → 768px にすると文字が **0.8倍 / 0.6倍**。CV（1024 キャッシュに描画）とも違う | `resize_to(out_width)` してから描く。`fontScale`・線幅は**最終表示幅**から決める |
| ③ | **検出0件でも2枚目を付けていた**（原画像と同一の画像＋「検出が描いてある」という説明文） | expG00 §39: 空の重畳は **−0.0429** | `render()` が None を返す＝単画像（学習・CV・コンテナで同一規則） |

## 4. 描画バリアント（`overlay_render.py`）

| id | 内容 | 狙い |
|---|---|---|
| r0 | 青塗り35% + 太輪郭 + 緑のクラス名（①②③ 修正済み） | 現行規約の素直な版 |
| r1 | r0 + **インスタンス番号**（`Clip 1` `Clip 2` …） | 計数（FRAME 最大の穴, number 0.47）の支援 |
| r2 | **クラス別の色分け**・画像に文字を描かず、色の凡例をテキストで渡す | 小さい文字を読ませない。②の影響を受けない |
| r3 | **2段 conf**（>=0.5 塗り+太輪郭+ラベル / 0.25-0.5 細輪郭 + `?`） | confidence を**画像で**渡す |
| T1 | 任意の描画 + 「Clip x3, Sponge x1」だけの短文 | 個数だけテキストで渡す |

- 色は**赤優勢を使わない**（組織・血液に溶ける。CLAUDE.md の規約）。r2 は青/シアン/黄/マゼンタ/緑/白/紫。
- クラス名・ラベル index は **ckpt の `config.json:id2label` から読む**（ハードコードしない）。
  expF38(8) / expF40(7) / expF39(clip 1) が混在するため。
